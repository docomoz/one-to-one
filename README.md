# vibe_coding

iOS-приложение для пар (можно пользоваться и одному): заметки, календарь и всё нужное в одном месте. Делаем вдвоём на SwiftUI с помощью Claude Code.

## Документы
- [docs/kickoff-prompt.md](docs/kickoff-prompt.md): стартовый промт, фазы работы и процесс.
- [docs/idea-brief-prompt.md](docs/idea-brief-prompt.md): промт для брифа по идее приложения.
- [CLAUDE.md](CLAUDE.md): правила проекта для Claude, читается автоматически в каждом чате.
- [docs/workflow.md](docs/workflow.md): как мы берём задачи и делаем PR.
- [docs/decisions.md](docs/decisions.md): журнал принятых решений.
