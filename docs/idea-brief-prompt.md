# Промт для Максима: бриф по идее приложения

> Как использовать: создать на своём компьютере пустую папку, открыть в ней Claude Code и вставить промт ниже. Положить скрины в папку `screens/` рядом. На выходе получится файл `idea.md`, его нужно передать Дарье (AirDrop или, когда появится репозиторий, через PR в `docs/idea.md`).

---

Помоги мне описать идею iOS-приложения так, чтобы другой Claude смог по этому описанию провести штурм и составить спецификацию. Мы делаем его вдвоём.

Суть: приложение для пар (можно пользоваться и одному), где собрано всё нужное вместе: заметки, календарь и прочее. Стек SwiftUI, нужны аккаунты и синхронизация между устройствами пары.

Задавай мне вопросы по одному, с вариантами ответа. Выясни:
1. Для кого приложение и какую проблему решает. Почему существующих приложений не хватает.
2. Главный сценарий: что пара делает в приложении в обычный день.
3. Список фич. Для каждой: что делает, как это видит пользователь, насколько важна (обязательно в первой версии / потом / мечта).
4. Что должно вызывать «вау».
5. Похожие приложения, которые нравятся или раздражают, и чем.
6. Скрины и референсы в папке `screens/`: посмотри их и опиши, что в каждом важно.

Не предлагай технических решений и не пиши код, это задача следующего этапа.

В конце запиши всё в `idea.md` с разделами: Суть, Для кого, Главный сценарий, Фичи (таблица с приоритетом), Вау-моменты, Конкуренты, Референсы, Открытые вопросы. Пиши кратко, без воды.
